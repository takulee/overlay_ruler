# Overlay Ruler

他のウィンドウの上に重ねて使える、**半透明のサイズ計測ツール**です。
全画面表示のアプリ内に表示されている画像など、画面上の一部分の大きさ(px)をすばやく確認できます。

## 特長

- 半透明の枠を **最前面** に表示し、他のアプリの上に重ねて測定できる
- 枠の **幅 × 高さ** と **左上の座標** をリアルタイム表示
- 枠は **ドラッグで移動・リサイズ**、矢印キーで **1px単位の微調整** が可能
- **高DPI対応**(表示倍率が100%でなくても、実際の画面ピクセルで計測)
- Ctrl + C で「幅x高さ」をクリップボードにコピー
- Python標準ライブラリ(tkinter)のみで動作。**追加インストール不要**

## 動作環境

- Windows
- Python 3.x(tkinter が使えるもの。通常のPythonインストーラなら同梱されています)

## インストール・起動

リポジトリをクローン(またはZIPをダウンロード)して、`overlay_ruler.pyw` をダブルクリックするだけです。
コンソール画面は表示されず、半透明の枠だけが現れます。

```bash
git clone https://github.com/takulee/overlay_ruler.git
cd overlay_ruler
pythonw overlay_ruler.pyw
```

> エラー内容を確認したい場合は `python overlay_ruler.pyw` で起動するとコンソールに出力されます。

## 使い方

1. 起動すると、画面上に半透明の枠が表示されます。
2. 測りたい対象の近くへ枠を移動し、端をドラッグして大まかに合わせます。
3. `Shift` + 矢印キーで1px単位の微調整をします。
4. 枠の端が対象の端にぴったり合ったら、枠の中央に表示されたサイズを読み取ります。
   `Ctrl` + `C` でコピーすることもできます。

### 表示内容

| 表示 | 内容 |
| --- | --- |
| `300 x 200 px` | 枠の幅 × 高さ |
| `(200, 200)` | 枠の左上の画面座標 |

### 操作一覧

**マウス**

| 操作 | 動作 |
| --- | --- |
| 枠の内側をドラッグ | 移動 |
| 枠の端・角をドラッグ | リサイズ |
| 右クリック | 終了 |

**キーボード**

| キー | 動作 |
| --- | --- |
| `←` `→` `↑` `↓` | 1pxずつ移動 |
| `Shift` + 矢印キー | 1pxずつリサイズ(`→` `↓` で拡大、`←` `↑` で縮小) |
| `Ctrl` + `C` | 「幅x高さ」をクリップボードにコピー(例: `300x200`) |
| `[` / `]` | 透明度を下げる / 上げる |
| `Esc` | 終了 |

## 注意事項

- **排他的フルスクリーン**で動作しているゲームやアプリでは、枠が表示されないことがあります。
  その場合は、アプリ側の設定を「ボーダーレスウィンドウ」または「ウィンドウ(最大化)」に変更してください。
- 計測できるのは **画面上に表示されているサイズ** です。アプリが画像を拡大縮小して表示している場合、元の画像ファイルの解像度とは一致しません。
- マルチモニター環境では、座標はWindowsの仮想デスクトップ座標で表示されます。
